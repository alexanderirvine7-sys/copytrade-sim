# Copy-trade experiment ($52 paper)

PAPER ONLY: pretend money. No real trades, wallets or exchanges are involved.

A static view of a 24-hour paper copy-trading simulation that follows the top weekly trader on Kolscan (Solana memecoins) at 0.25x size, starting from a pretend $52.
`data.json` is computed on a separate machine from public data (Solana RPC, Kolscan, Jupiter and DexScreener prices) and pushed here about once a minute; `index.html` renders it.
